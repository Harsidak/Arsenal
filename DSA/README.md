# DSA

Topic-first data structures & algorithms practice — implementation notes, not contest solutions (those live in `CodeForces/`).

**Languages**: C++ for competitive programming, C for edge/bare-metal systems.  
**CP Template**: [`template.cpp`](template.cpp) — fast I/O, common macros, ready to go.

One folder per topic, lowercase snake_case (`binary_search/`, `dynamic_programming/`, `graphs/`, ...), created as needed. Code here is meant to be reusable — the same topic implementation should be usable as reference both when solving a CodeForces problem and when a technique is needed inside a larger ML/systems project.
