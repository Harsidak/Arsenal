# Axler — Linear Algebra Done Right

Exercises and derivations from **Sheldon Axler's Linear Algebra Done Right**.

## Structure

One folder per chapter. Each has:
- `exercises.md` — written proofs, derivations, scratch work
- `*.py` — computational verification (optional, when useful)
