# Projects

Short, scoped implementation exercises — building a known architecture or technique (e.g. a RAG pipeline, an agentic loop) from a paper or concept, purely to understand how it works end-to-end.

This is **not** portfolio or production work. A real, specialized project (e.g. a domain-specific RAG system with a custom dataset meant to go in a portfolio) belongs in its own separate GitHub repository, not here.

One folder per exercise, named after the architecture/paper (`rag/`, `agentic_loop/`, ...).
