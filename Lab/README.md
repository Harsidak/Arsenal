# Lab

Flexible ML/research practice space.

- **`Books/`** — exercises reinforcing a specific book's teachings, one folder per book (`axler_linear_algebra/`, `joseph/`, `fluent_python/`, ...).
- **`Libraries/`** — learning a new tool, one folder per library/language (`pytorch/`, `numpy/`, `jax/`, `java/`, ...).
- **`Projects/`** — see [Projects/README.md](Projects/README.md).
- **`scratch/`** — zero-friction throwaway space. Pre-loaded templates for math verification (`math.py`), ML experiments (`experiment.py`), C++ (`scratch.cpp`), and C (`scratch.c`). Nothing here is precious — try things, break things, delete things.
