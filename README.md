# 🛡️ The Arsenal

> **Welcome to the Arsenal:** a personal vault and practice ground for becoming an elite AI/ML researcher — knowledge base, competitive programming archive, and hands-on ML practice in one place.
> 
> **Objective function:** maximize the rate of mistakes made and learned from.

This repository tracks my synthesized notes, practice work, and research experiments.

## 📂 Structure

### 🔴 Daily Drivers
- **[`MISTAKES.md`](MISTAKES.md)** — Raw error log. Every mistake is a data point. Log it, extract the pattern, never repeat it.
- **[`PROTOCOL.md`](PROTOCOL.md)** — What to practice every day. Non-negotiables, weekly rituals, monthly audits.

### 🧠 Arsenal Vault
Obsidian vault — my own atomic notes, organized under `ME/` by a numbered taxonomy (`1_FOUNDATIONS` ... `5_MIND_AND_MISSION`). Edited manually; see `ME.md` for the index.

### 💻 CodeForces
Contest solutions — an archive of algorithmic problem-solving and logic building, organized by round. `SOLVED/` is a flat archive of older one-off solves.

### 🧮 DSA
Topic-first data structures & algorithms practice. C++ for competitive programming, C for edge/bare-metal systems. See [DSA/README.md](DSA/README.md).

### 🧪 Lab
Flexible ML/research practice space:
- **`Books/`** — chapter-by-chapter exercises (Axler, Joseph, Fluent Python)
- **`Libraries/`** — learning tools hands-on (PyTorch, NumPy, JAX)
- **`Projects/`** — scoped paper implementations
- **`scratch/`** — zero-friction throwaway space (pre-loaded templates, open and start typing)

See [Lab/README.md](Lab/README.md).
